# 開發者參考 — 資料結構與注意事項

一般使用本 skill 不需要看此檔，僅在維護 `scan.py`、新增聚合邏輯、調整輸出格式時參考

## 重要欄位（聚合用）

`scan.py` 從每站查詢結果中讀取以下欄位來建報告：

| 欄位 | 說明 |
|------|------|
| `commodityCode` | 商品代碼，聚合用 key (如 `31Z011082`) |
| `commodityName` | 商品名稱 (如 `BUBU切片組-常態`) |
| `Price` | 售價 (整數，TWD) |
| `quantity` | 該站剩餘數量 |

單一站點 stock list 通常 0–5 項；同一商品不會在同站重複；空陣列表示該站目前沒上架任何商品

- BUBU 切片組-常態（`31Z011082`）
- 四入生乳蒸布丁禮盒（`31Z014127`）
- 巴斯克生起司（`31Z064078`）
- 三顆布丁生乳捲（近期爆紅，常被秒空）

商品會隨亞尼克官方上架/下架而變動，本工具的聚合邏輯不依賴商品白名單，新商品會自動出現在報告中

## 站點清單

`scripts/stations.tsv` 是 2026-05 的快照，內含站點代碼 / 路線 / 站名，**僅作為 fallback** 使用；`scan.py` 預設會在每次執行時即時取得最新清單

## 注意事項

- 試營運站名後面可能帶「(試營運中，X/XX 正式開幕)」之類後綴，`stations.tsv` 已清理為純站名
- 失敗站點不會中斷流程，會記錄在報告底部的「查詢失敗站點」段落

## 系統需求

- 只需 **Python 3.8+**，macOS / Linux 預設內建，Windows 從 [python.org](https://python.org) 安裝
- 全部使用 Python 標準函式庫：`urllib`、`json`、`csv`、`concurrent.futures`、`collections`、`datetime`
- **不需 `pip install` 任何套件、不需 curl、不需 jq**

## 效能特性

實測（家用 100Mbps）：

- 預設併發 6、retry 0–2 次：約 **25–35 秒**
- 併發 3：約 **45–60 秒**
- 併發 12：約 **18–25 秒**（再高邊際效益遞減）

`CONCURRENCY=6` 是兼顧速度與「不對官方造成負擔」的預設值，**請勿任意調高**
